# חיבור ל-Railway — Claude Code Skill

יש דברים שאתה רוצה שיקרו כשאתה לא ליד המחשב. סוכן שעונה ללקוחות בעשר בלילה,
בריף שמחכה לך בבוקר, בוט שמקבל הודעות כל היום.

בשביל זה צריך **שרת** — כתובת קבועה באינטרנט שתמיד דלוקה. המחשב שלך בבית
הוא לא כתובת כזאת.

הסקיל הזה מחבר את Claude Code ל-Railway מקצה לקצה. **אתה עושה דבר אחד:
לוחץ על לינק ומאשר בדפדפן.** כל השאר קורה לבד.

---

## מה קורה כשמריצים

1. הסקיל מריץ **בדיקת מוכנות** ורואה מה כבר קיים אצלך — ואם הכל מחובר,
   הוא אומר את זה ולא נוגע בכלום
2. מתקין את ה-Railway CLI לפי מערכת ההפעלה שלך. לא שואל אותך מה יש לך
3. **נותן לך לינק וקוד.** אתה פותח, מאשר, וזהו
4. מתקין את **ה-MCP הרשמי של Railway** לתוך Claude Code
5. מאמת שהכל עובד ומדפיס מה מחובר

מהרגע הזה **קלוד מנהל את Railway בשבילך.** אתה מבקש בשפה רגילה:

```
תפרוס לי את התיקייה הזאת
תראה לי את הלוגים של השירות
תוסיף משתנה סביבה
מה הכתובת של השירות?
```

**אתה לא לומד אף פקודה של Railway.**

---

## מה צריך

1. **Claude Code** מותקן
2. **חשבון Railway** — אין? הסקיל ישלח לך קישור עם **20$ קרדיט מתנה**.
   כדאי להירשם עם אותו חשבון GitHub שאתה עובד איתו, זה מקצר בהמשך
3. שרת עולה בסביבות **5$ לחודש**. אומרים את זה מראש, ולא מפתיעים אותך בחשבון

---

## התקנה ושימוש

1. פותחים Claude Code בתיקייה שבה תרצו לעבוד
2. מדביקים את הלינק לריפו וכותבים: **"תתקין לי את הסקיל שנמצא כאן בפרויקט הנוכחי"**

```
תחבר אותי ל-Railway
```

**אחרי שזה מסתיים — צריך להפעיל מחדש את Claude Code.** כלים חדשים נטענים
בעלייה, ובלי זה תחשוב שזה לא עבד.

---

## שלוש המלכודות שהסקיל שומר עליך מהן

אלה לא אזהרות בטקסט — הן **בדיקות שהסקיל מריץ**.

| | מה קורה | למה זה כואב |
|---|---|---|
| 🔴 **שירות ריק** | יצירת שירות מייצרת אותו **ריק**. בלי לחבר את הריפו אליו, `git push` **לא פורס כלום** | מתגלה **שבוע אחרי** ההקמה, כשאתה משנה קוד ולא מבין למה כלום לא קרה. בלי שגיאה |
| 🟠 **קבצים שנמחקים** | Railway מוחק את מערכת הקבצים **בכל עדכון ובכל restart** | הסוכן זוכר תוך כדי שיחה, ומתחיל מאפס מול כל לקוח אחרי כל עדכון. נראה כמו באג בקוד |
| 🟡 **קישור שאבד** | התנתקות מוחקת גם את **קישורי הפרויקטים**, לא רק את ההזדהות | פקודות פריסה נשברות בלי סיבה מובנת. מתועד, ולא באג |

## מה הסקיל לא עושה

- **לא מבקש ממך טוקן בצ'אט.** אף פעם. ההזדהות עוברת בדפדפן בלבד
- **לא מתנתק בשמך.** התנתקות מוחקת את קישורי הפרויקטים, ולכן זו פעולה
  שרק אתה מריץ, ורק אחרי שהסבירו לך מה היא עושה
- **לא נוגע בחיוב** — לא משדרג תוכנית, לא מוסיף כרטיס, לא מגדיל שירות
- **לא נוגע בהגדרות ה-shell שלך** — לא מוסיף שורות ל-`.zshrc` ולא "מסדר" PATH
- **לא כותב את האפליקציה** שתיפרס. הוא מחבר ופורס, וזה הכל
- **לא מנטר ולא מנהל תשתית.** אחרי הפריסה הראשונה זה שלך

## הבדיקה שאתה יכול להריץ בעצמך

```bash
bash .claude/skills/railway-connect/scripts/doctor.sh
```

מדפיסה מה מחובר ומה חסר, ומסתיימת בשורה שאומרת מה הצעד הבא. **זה מקור
האמת** — גם הסקיל עצמו נשען עליה ולא על "נראה לי שזה עבד".

---

## בדיקות

```bash
node tests/run-tests.mjs
```

רצות **בלי שום מפתח ובלי חשבון** — בדיוק המצב של מי שמתקין בפעם הראשונה.
בדיקת גיטהאב מפנה את `gh` לתיקיית קונפיג זמנית, ולכן היא לא נוגעת
בהזדהות שלך.

| | למה זה שם |
|---|---|
| שער הגרסה 5.44.0 | מתחתיה אין `mcp install`, וזה נראה כמו "פקודה לא נמצאה" |
| הפקודות קיימות, כולל `--browserless` | הדגל נעלם → זרימת הלינק נשברת |
| **פרסור הלינק של Railway** | הפורמט משתנה → הסקיל מפסיק להגיש לינק, **והמשתמש רואה סוכן שנתקע בלי שגיאה** |
| **הקוד והלינק של גיטהאב** | ומוודא שהקוד עדיין **נפרד** מה-URL — אם יטמיעו אותו, ההגשה צריכה להשתנות |
| `doctor.sh` מסיים בתקציב זמן | גרסה מוקדמת נתקעה על `claude mcp list`, שבודק בריאות של כל שרתי ה-MCP |

**מה שהבדיקות לא יכולות לעשות:** ללחוץ. סגירת הלופ אחרי האישור נבדקת רק
על מכונה עם בן אדם.
